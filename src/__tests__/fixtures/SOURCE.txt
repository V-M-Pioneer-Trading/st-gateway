The commit above is the head of meta pull request #108, "Fixture v7: a non-2xx
answer is unavailable whatever its body says". That pull request is merged
with a merge commit, not squashed, so this commit lands on meta's main
unchanged; had it been squashed, the commit above would be replaced with the
squash commit, and the blob, bytes and sha256 would not change. Version 7 adds
five calling-service cases and five gateway cases,
gateway-center-returns-{500,401,302,503,404}-with-active-body: the center
answers a non-2xx with a valid active operator body, and the lane is
background, never interactive. clerk-client refuses any non-2xx before reading
the body (since 1.0.0), so no bump is needed; the cases pin it.

Version 6 (meta #107, commit 993fea9) added
gateway-center-returns-case-variant-duplicate-key; clerk-client 2.0.1 is the
first release that passes it.

st-gateway drives the nineteen gatewayCases only. The fifty-six calling-service
cases describe a verdict (proceed, 401, 403, 503), and the gateway never
reaches one: it picks a queue lane and nothing else. Those cases are driven by
clerk-client's own suite, which vendors the same version. The
conformance test here skips them by name and asserts their count, so a case
added upstream in either group fails here until someone decides what it
means for the gateway.

The sha256 is over the LF bytes of the blob as git stores it, which is what
`git show <commit>:fixtures/introspection.json` prints.
src/__tests__/lane.conformance.test.ts recomputes it on every run and fails if
the vendored copy and this record disagree, so a hand-edit of the copy is a
red test rather than silent drift.

To re-vendor after meta changes the fixture:

  git -C ../meta show HEAD:fixtures/introspection.json > src/__tests__/fixtures/introspection.json
  node -e "const c=require('crypto'),f=require('fs');const b=f.readFileSync('src/__tests__/fixtures/introspection.json');console.log(b.length,c.createHash('sha256').update(b).digest('hex'))"

then update the commit, blob, date, version, bytes and sha256 above, and the
constants at the top of the conformance test. Change meta first; a copy that
leads the original is drift pointing the other way.
